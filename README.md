# Data Cleanup Pipeline

A Python-based data cleaning framework designed to automate
the preprocessing stage of data analytics and machine learning projects.

## Features

- Missing value detection and imputation
- Duplicate removal
- Outlier detection and treatment
- Data normalization
- Data quality reporting
- Exploratory visualizations

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Workflow

Raw Data → Validation → Cleaning → Transformation → Visualization → Processed Data
